# Ordblindapp / ReliefRead

A readability-first app for dyslexic and borderline readers. It includes calm reading settings, read-aloud, word highlighting, phonetic writing support, notes, lookups, and shareable reading snapshots.

## Deployment

This repository is configured to deploy to GitHub Pages from `reliefread-app-public-github-pages.zip` using GitHub Actions.

The zip is intentionally public-safe and should not contain database exports or private user data.
